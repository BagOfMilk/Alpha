# Арт-директор «Рингу»: шпаргалка (повне — `docs/ring/DESIGN_SYSTEM.md`)

## 0. Протокол (рішення власника 06.11.2026)
Створюєш чи змінюєш видиме? **У0** — спершу ТЕКСТОМ арт-директору (`SendMessage` до сесії «Дизайн-система игры»,
`local_d6c18264-ca16-4c92-bf0f-9335958f328c`): що, де, які токени, що нового. **У1** — low-poly/чорновик на перегляд.
**У2** — кадри з білду + чекліст Д1–Д6. Відповідь: «ОК/правки». Без У0 — лише дрібні правки без нових кольорів, форм,
шрифтів і без зміни розкладки. У коміті: «Ворота: У0/У1/У2 — так/ні».
**Палітра — лише в директора:** нових кольорів не вигадуй і не перевіряй наперед — бери з токенів або проси.

## 1. Токени (`RingTheme` у коді, `brand_tokens.json` — джерело)
| Сенс | Токен | Hex |
|---|---|---|
| тло / панель / піднята / межа | `Bg` / `Panel` / `PanelRaised` / `Border` | `#0E0D12` `#17151D` `#221F2B` `#2E2A39` |
| текст / другорядний / недоступне | `Text` / `TextDim` / `Disabled` | `#EDE5D6` `#9A948A` `#6B6672` |
| успіх, нагорода, головна дія ГРАВЦЯ | `Gold` (`Reward`, `PrimaryAction`, `Strong`) | `#E8BA3C` |
| шкода, провал, небезпека | `Signal` (`Damage`, `Miss`) | `#E5483F` |
| герой / лиходій / бунтар | `Hero`+`HeroText` / `Villain`+`VillainText` / `Rebel` | `#2F6FD6`+`#6DB6FF` / `#AA141C`+`#E5483F` / `#FF7AB8` |
- Кармін `#AA141C` — лише поверхні (контраст 2,4 — не текст). Зеленого й бурштинового немає.
- Заборонено в Ring-коді: `new Color(`, `#RRGGBB`, `Color.red/white/…`, `FontDefinition.FromFont`/`LoadFont` поза темою,
  кегль <15 для інформації (охоронець `RingDesignGuardTests`, храповик — нові відхилення червоні).

## 2. Шрифти
Дисплей і мітки — Sofia Sans Extra Condensed 700–900, **лише ВЕЛИКІ** (її малі кириличні — болгарські форми: г як r,
д як g, и як u; завжди `RingTheme.Caps()`), ≤2 слів; знака ₴ немає — гроші зі знаком у ролі text. Текст і речення —
Fixel Text; від руки/спрей (Amatic SC, Rubik Spray Paint) — лише у 3D-світі. Похил −12° лише для ВЕЛИКИХ.
Новий шрифт: тест «Їжак Єнот Ґанок» на рівні гліфа + Є І Ї Ґ; OFL (ліцензія поруч). Слів у текстурах немає: усе ключами.

## 3. Відгук світу (виноски)
T0 провал 36 · T1 частково 46 · T2 чисто/реверс 72 · T3 «НА ДВА!» 80 · T4 фінішер 96 · T5 перемога/поразка 110 (кегль @900).
Золота пластина — лише успіх ГРАВЦЯ; успіх суперника — темна пластина з сигнал-обводкою; позиція — на боці того, хто діє.
Вхід 80 мс з перельотом 1,25 через `transform` (не `fontSize`), hit-stop ≤70/120 мс, текст не накриває обличчя.
Поразка — холодна й тиха; свято лише на користь гравця.

## 4. Арени
Три щаблі (спортзал → клуб → Палац): ті самі токени, інша інтенсивність фактури/світла. Архітектура темніша й нейтральніша
за афіші. Знак: печатка без планки; вордмарк = канатна рамка + живий текст. Вивіски — лише з `venue_*_texts.txt`.

## 5. Чекліст Д1–Д6 (на У2)
Д1 тільки токени · Д2 «3 секунди» (перше/друге читання) · Д3 контраст і дальтонізм · Д4 «Їжак Єнот Ґанок» на всіх кеглях ·
Д5 кадри до/після, **переглянуті очима** · Д6 PERF-01 (без blur, без перерахунку розкладки щокадру).
Звіт — «очима / тестом / не перевірено (чому)».
