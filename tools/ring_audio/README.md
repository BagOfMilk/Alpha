# tools/ring_audio — процедурна музика й SFX меню «Рингу» (брутальний напрям)

Чистий Python 3 + numpy (без scipy, ffmpeg, sox). Нічого не встановлювати. Усе детерміноване
(фіксовані зерна): повторний запуск дає побайтово ті самі WAV (перевірено порівнянням md5
двох повних рендерів).

Напрям — рішення власника 07–08.11.2026: «Роби звук більш брутальний меньше радості».
Попередня версія (acid jazz / фанк-рок, фа мінор, Rhodes, яскраві духові, свінг) замінена
повністю: мі мінор / мі фрігійський, силові акорди, важкі барабани, перевантажені бас і
гітари, низькі духові, метал. Повний опис і брифи — `docs/ring/audio/MENU_AUDIO.md`.

## Запуск

З каталогу `tools`:

```
python -m ring_audio.render_menus                       # усе -> Assets/Art/Ring/Audio/Menu
python -m ring_audio.render_menus --only music_login    # один файл (маніфест не оновлюється)
python -m ring_audio.render_menus --only sfx            # лише 10 SFX
python -m ring_audio.render_menus --out DIR --stems DIR # стеми по групах (не комітяться)
python -m ring_audio.loudness                           # самоперевірка вимірювача гучності
```

На Windows задайте `PYTHONIOENCODING=utf-8`, щоб консоль не псувала українські рядки.
Повний рендер ≈ 1,3 хв. Формат — WAV 16 біт 48 кГц (музика стерео, SFX моно); Unity стискає
у Vorbis при імпорті. Під час рендеру друкується RMS по секціях Входу й по стемах.

## Модулі

| Файл | Що робить |
|---|---|
| `synth.py` | Інструменти: брудний бас (пилка+квадрат через вейвшейпер + чистий суб на октаву нижче), гітара-«чаг» (стос розстроєних polyBLEP-пилок → жорсткий вейвшейпер → «кабінет» HP 90 Гц / LP), низький перевантажений лід, низькі духові (повільна атака, темний зріз), темний падь, низький розстроєний дзвін/піаніно, барабани (бочка з довгим субом і жорстким кліком, товстий малий із короткою «гейтованою» кімнатою, підлогові томи, темний крештоп, глухий хет), металеві удари (неспівзвучні парціали), суб-дроп, зворотне наростання, свист, стрічковий шум, сталевий «тик». Біквади через FFT, змінний зріз — перемішування фіксованих фільтрів. |
| `motif.py` | Лейтмотив (8 тактів), гармонія 4-тактового кола (E5 / E5→F5 / G5→F5 / E5+B♭5), силові акорди, коріння. |
| `mix.py` | Сітка 1/16 без свінгу, детермінована гуманізація (час і динаміка), панорама, **циклічна** згортка реверба й фільтрів (шов петлі безшовний за побудовою), піковий компресор, лімітер з випередженням, підбір до -16 LUFS, 16-бітний вивід з дитером, звіт про шов. |
| `loudness.py` | BS.1770-4: K-зважування (стандартні коефіцієнти 48 кГц), блоки 400 мс з перекриттям 75 %, абсолютний гейт -70 LUFS, відносний -10 LU; істинний пік (4× через доповнення нулями у спектрі). Не змінювався. |
| `render_menus.py` | Аранжування трьох треків, дизайн 10 SFX, маніфест, LICENSE.md, CLI. |

Дрони (Завантаження, Налаштування) — строго періодичні за довжиною петлі (цілі цикли
синуса, цілі цикли повільного «дихання»), тому безшовні без жодного кросфейду. Усе інше
(реверб, фільтри, хвости нот) загортається через край циклічно.

## Заміри (прочитано назад із записаних WAV, після 16-бітного квантування)

| Файл | Тривалість | Семпли | BPM | Такти | LUFS | dBTP | Піковий фактор |
|---|---|---|---|---|---|---|---|
| music_login | 80,000 с | 3 840 000 | 96,000 | 32 | -16,00 | -1,74 | 15,8 дБ |
| music_loading | 40,000 с | 1 920 000 | 96,000 | 16 | -16,00 | -3,01 | 13,5 дБ |
| music_settings | 54,880 с | 2 634 240 | 69,971 | 16 | -16,00 | -3,32 | 14,0 дБ |

Фактичний темп Налаштувань трохи відхиляється від номінальних 70 (довжину петлі округлено до
гладкого числа, кратного 480 семплам: швидкий FFT і ціла кількість семплів); Вхід і
Завантаження вийшли рівно на 96. Темп Входу й Завантаження підтверджено незалежно —
автокореляцією низькочастотної огинаючої (довжина такту 2,5 с → 96,0 BPM); у Налаштувань
серцебиття надто тихе для такого виміру, там темп — за побудовою сітки.

Динаміка секцій Входу (RMS, дБFS; «до ланцюга» — зведення до стискання й нормалізації,
«у файлі» — після неї):

| Секція | Такти | До ланцюга | У файлі |
|---|---|---|---|
| A — груув | 1–8 | -24,6 | -20,0 |
| B — тема | 9–16 | -21,6 | -17,0 |
| C — зривка | 17–24 | -28,5 | -23,9 |
| D — усе | 25–32 | -18,9 | -14,4 |

C на 3,9 дБ тихіша за A, D найгучніша (A + 5,6 дБ). Для Налаштувань: перший прохід -16,3, другий
(рідше) -18,7 дБFS.

Шов петлі (останній семпл → перший), амплітуда 0..1: «розрив» — різниця між останнім і
першим семплом; «макс. у ±10 мс» — найбільша різниця сусідніх семплів у вікні ±10 мс
навколо шва (там завжди сидить транзієнт бочки чи зворотного наростання).

| Файл | Розрив на шві | Перцентиль серед різниць сусідніх | p99 різниці | Макс. у ±10 мс |
|---|---|---|---|---|
| music_login | 0,046 | 98,2 | 0,065 | 0,143 |
| music_loading | 0,073 | 99,7 | 0,044 | 0,261 |
| music_settings | 0,006 | 57,9 | 0,016 | 0,025 |

Розрив на шві менший за найбільші звичайні різниці поруч, тобто не помітніший за природний
транзієнт музики (для Завантаження він вищий за p99, бо на шві стоїть удар бочки; сусідні
семпли того удару змінюються майже вп'ятеро різкіше). Без DC (середнє < 5·10⁻⁵), кліпованих
семплів немає.

Спектр (частка енергії): Вхід — <120 Гц 37 %, 120–500 Гц 52 %, 500–2 кГц 9 %, вище 2 кГц 1,5 %;
Завантаження — <120 Гц 64 %, 120–500 Гц 33 %; Налаштування — <120 Гц 33 %, 120–500 Гц 65 %.
Тобто звук навмисно темний. Кореляція каналів у діапазоні 30–150 Гц ≥ 0,9 (бас і бочка по
центру), у 0,4–3,5 кГц 0,64–0,76 (гітари рознесені).

Цілі гучності виставлено за ролями (службові звуки — тихіші, підтвердження й вхід — гучніші),

закінчуються нулем (fade-in/out), без клацань на межах.

## Що не перевірено

Нічого з цього не прослухано вухом: перевірено числами (LUFS, dBTP, шов, баланс смуг,
кореляція каналів, відсутність кліпів і DC, темп автокореляцією) і спектрограмами/формами
хвилі, які дивилися очима. Тембри (перевантажені гітари, бас, низькі духові, дзвін) — синтез,
а не живий запис; чи «звучить брутально» і чи розбірлива мелодія лейтмотиву під перевантаженням
— оцінка на слух. Для живішого звучання є брифи у `docs/ring/audio/MENU_AUDIO.md`.
Цільова гучність у грі залежить від шини Music/SFX у мікшері.
