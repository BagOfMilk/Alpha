# tools/ring_audio — процедурна музика й SFX меню «Рингу»

Чистий Python 3 + numpy (без scipy, ffmpeg, sox). Нічого не встановлювати. Усе детерміноване
(фіксовані зерна): повторний запуск дає побайтово ті самі WAV.

## Запуск

З каталогу `tools`:

```
python -m ring_audio.render_menus                       # усе -> Assets/Art/Ring/Audio/Menu
python -m ring_audio.render_menus --only music_login    # один файл (маніфест не оновлюється)
python -m ring_audio.render_menus --out DIR --stems DIR # стеми по інструментах (не комітяться)
python -m ring_audio.loudness                           # самоперевірка вимірювача гучності
```

На Windows задайте `PYTHONIOENCODING=utf-8`, щоб консоль не псувала українські рядки.
Повний рендер ≈ 1,5 хв. Формат — WAV 16 біт 48 кГц (музика стерео, SFX моно); Unity стискає
у Vorbis при імпорті.

## Модулі

| Файл | Що робить |
|---|---|
| `synth.py` | Інструменти: слеп-бас (адитивний щипок + транзієнт, «поп», «привид»), Rhodes (FM-«дзвоник» 1:14 на тілі 1:1), духові (4 розстроєні polyBLEP-пилки на ноту, швидка обвідна зрізу, підтягування тону), wah-«чоп» гітари, барабани (бочка, малий, привидні, хети, рим, щітка, томи, крештоп), падь, тріск вінілу, SFX-кубики (клац, свист). Біквади через FFT, змінний зріз — перемішування фіксованих фільтрів. |
| `motif.py` | Лейтмотив (8 тактів), акорди, цикл гармонії, діатонічна гармонізація, запис нотами. |
| `mix.py` | Сітка 1/16 зі свінгом, детермінована гуманізація (час і динаміка), панорама, **циклічна** згортка реверба й фільтрів (шов петлі безшовний за побудовою), піковий компресор, лімітер з випередженням, підбір до -16 LUFS, 16-бітний вивід з дитером, звіт про шов. |
| `loudness.py` | BS.1770-4: K-зважування (стандартні коефіцієнти 48 кГц), блоки 400 мс з перекриттям 75 %, абсолютний гейт -70 LUFS, відносний -10 LU; істинний пік (4× через доповнення нулями у спектрі). |
| `render_menus.py` | Аранжування трьох треків, дизайн 10 SFX, маніфест, LICENSE.md, CLI. |

## Самоперевірка вимірювача (`python -m ring_audio.loudness`)

| Сигнал | Результат | Очікування |
|---|---|---|
| 1 кГц, 0 dBFS, 1 канал | -3,004 LUFS | ≈ -3,01 |
| 1 кГц, 0 dBFS, стерео (однакові канали) | +0,007 LUFS | ≈ 0,00 |
| 1 кГц, -20 dBFS, стерео | -19,993 LUFS | ≈ -20,0 |
| 1 кГц, -20 dBFS, 1 канал | -23,004 LUFS | ≈ -23,0 |
| істинний пік синуса 997 Гц, 0 dBFS | 0,000 dBTP | 0 |

## Заміри (після 16-бітного квантування)

| Файл | Тривалість | Семпли | BPM (факт.) | Такти | LUFS | dBTP |
|---|---|---|---|---|---|---|
| music_login | 66,150 с | 3 175 200 | 116,10 | 32 | -16,00 | -1,56 |
| music_loading | 33,000 с | 1 584 000 | 116,36 | 16 | -16,01 | -1,26 |
| music_settings | 45,760 с | 2 196 480 | 83,92 | 16 | -16,00 | -5,80 |

Фактичний темп трохи відхиляється від номінального (116/116/84): довжину петлі округлено до
гладкого числа, кратного 480 семплам (швидкий FFT і ціла кількість семплів).

Шов петлі (останній семпл -> перший), амплітуда 0..1:

| Файл | Розрив на шві | Медіана різниці сусідніх семплів | p99 різниці | RMS 10 мс до шва / після |
|---|---|---|---|---|
| music_login | 0,0225 | 0,0138 | 0,108 | 0,081 / 0,183 |
| music_loading | 0,0620 | 0,0068 | 0,113 | 0,202 / 0,370 |
| music_settings | 0,0031 | 0,0048 | 0,049 | 0,042 / 0,236 |

Розрив на шві менший за p99 різниць сусідніх семплів (тобто не помітніший за звичайний
транзієнт). Різниця RMS — музична: перша доля (бочка + бас) гучніша за кінець такту; хвости
реверба та релізи ламаються через край без стрибка. Без DC: середнє < 3·10⁻⁴.

SFX (моно; гучність — усього кліпу як dual-mono, оскільки 400-мс блоку для 40-мс звуку немає):

| Файл | мс | пік dBTP | гучність кліпу, LUFS | миттєва макс., LUFS |
|---|---|---|---|---|
| ui_move | 75 | -8,4 | -12,4 | -19,7 |
| ui_confirm | 240 | -3,5 | -14,8 | -17,0 |
| ui_back | 160 | -8,0 | -12,4 | -16,4 |
| ui_error | 340 | -2,5 | -15,7 | -16,4 |
| ui_toggle | 120 | -9,0 | -13,4 | -18,6 |
| ui_slider | 50 | -10,0 | -13,6 | -22,6 |
| ui_tab | 170 | -6,0 | -16,4 | -20,1 |
| ui_transition | 500 | -2,9 | -15,3 | -14,3 |
| ui_load_done | 800 | -5,0 | -15,4 | -12,6 |
| ui_login_ok | 1380 | -3,8 | -14,3 | -12,6 |

Ролі розставлені піком: службові звуки (рух, слайдер, перемикач) тихіші, підтвердження і
помилка — гучніші; розкид гучності кліпів ≈ 4 дБ (-12,4…-16,4 LUFS). Стандартний гейтований вимір BS.1770 для моно-кліпів ≥ 400 мс (`ui_load_done`, `ui_login_ok`, `ui_transition`) дає ≈ -17,3 LUFS (на ~1 дБ нижче dual-mono); для коротших блоку 400 мс немає (-99).

## Що не перевірено

Нічого з цього не прослухано вухом: перевірено числами (LUFS, dBTP, шов, баланс смуг по
тактах, відсутність кліпів і DC) і спектрограмами. Тембри (особливо духові й слеп-бас) —
синтез, а не живий запис; для живішого звучання є брифи у `docs/ring/audio/MENU_AUDIO.md`.
Цільова гучність у грі залежить від шини Music/SFX у мікшері.
