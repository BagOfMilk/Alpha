# Alpha — Base-Builder RPG (Unity)

Сюжетная RPG: ведёшь кастомного протагониста-лидера, развиваешь живой город-базу,
собираешь ростер именных напарников и ходишь в тактические бои (в духе
**Wasteland 3** — гибкий пул очков действий, индивидуальная инициатива, укрытия +
надёжный %), авторские миссии и процедурные вылазки за лутом и материалами.

> **Источник истины по дизайну — [`docs/GDD.md`](docs/GDD.md) (v6).** Как это
> реализует код — [`docs/DESIGN.md`](docs/DESIGN.md). Числа баланса —
> [`docs/BALANCE.md`](docs/BALANCE.md).

> Логика и баланс написаны на **чистом C#** (папка `Assets/_Project/Scripts/Core`,
> без UnityEngine), чтобы их было легко читать, тестировать и крутить по цифрам
> без запуска движка.

## Как открыть проект (с компьютера)

1. Установи **Unity Hub** → https://unity.com/download
2. В Unity Hub поставь **Unity 6.4** (версия `6000.4.10f1`). Точную версию проект
   подскажет сам — Hub предложит её при открытии.
3. Склонируй репозиторий (или скачай ZIP) и в Unity Hub нажми **Add → Add project
   from disk**, выбери папку с проектом.
4. Открой проект. Unity сам сгенерирует папки `Library/`, `.csproj` и т.п.
   (они в `.gitignore` и в репозиторий не попадают — это нормально).

## Как увидеть, что всё работает

Без интерфейса, прямо в редакторе (**GameObject → Create Empty → Add Component**):

**`Base Game Demo`** — петля базы. В консоли: **лист персонажа** (атрибуты →
производные, скилы, трейты), **петля времени** (лечение в днях, стройка, население),
шрам от Серьёзного ранения, детерминированные проверки, ресурсы отряда.

**`Combat Demo`** — вертикальный срез боя: автостычка **4 напарника против 6 врагов**
(Громила, 2 застрельщика, дрон-контролёр, 2 гуля) на карте с укрытиями и стеной.
В консоли: порядок инициативы и полный лог (укрытия и фланги, граза, криты, Шред,
Подавление, Кровотечение, даун + стабилизация медиком, Strike-метр) с итогом.
Сид фиксирован — бой воспроизводим: крути `BalanceConfig` и сравнивай исходы.

**`Expedition Demo`** — полная петля города: назначения → отправка отряда (позиции
пустеют) → путешествие в днях → бой 4×6 → возврат (лут, ранения/шрамы в ростер,
XP) → лечение в Лазарете. Та самая петля из Эпика 1 GDD, целиком в консоли.

**`Threats Demo`** — скрытые шкалы за ~45 дней: тихая декада → жёсткие квестовые
выборы (их эффект скрыт) → город растёт и полосы ползут Calm→Critical → инциденты
с резолвом через позиции (пустой склад = худшие исходы), кризис с оттоком людей,
одноразовый всплеск «Удар по своим» → разрядка. Чисел нигде нет — только полосы
и амбиент-реплики города.

**`Council Demo`** — совет и фракции: прогон действий (Облава гасит Напряжение, но
злит Вольных; Дипломатия тянет фракцию; Подготовка растит Готовность; Инвестиция
капает золото по дням) и квест-выбор с рябью по нескольким системам. Наружу —
только полосы фракций/репутации/Напряжения/Готовности, без чисел.

**`Items Demo`** — лут/гир/крафт: дроп с сидом (редкость множит роллы) → экипировка
(производные до/после через единый агрегатор) → бой с уникальным проком именной
винтовки «Вдоводел» (Кровотечение) → крафт-апгрейд за крафтовый компонент.

**`Dungeon Demo`** — данж push-your-luck: отряд лезет вглубь (бои/схроны/проверки/
события), на глубине экстрактится (банк) — или вайп губит незабанкованное.

**`Quests Demo`** — квесты и сюжетные миссии: «Пропавший караван» end-to-end
(проверка → выбор с **видимыми** реакциями напарников и **скрытой** рябью Напряжения
→ бой → награда), телеграф **обходимой** леталки «Минный проход», и цепочка дублёров
спайна (бит понёс лидер → пал → подхватил understudy).

**`Companions Demo`** — драма ростера: ценностные связи и баентер → гибель напарника
с рябью лояльности по связям (каскад **огорожен**) → уход бойца в антагонисты со
своим гиром → бой с боссом-перебежчиком → возврат гира убийством.

Это «исполняемая спецификация» — удобно сверять баланс на глаз до интерфейса.

## Тесты

**Window → General → Test Runner → EditMode → Run All.** 179 тестов: производные
статы, прокачка, проверки, трейты/шрамы, агрегатор модификаторов, петля базы,
боевое ядро (укрытия/LOS, попадание/граза, конвейер урона, ходы и состояния,
даун/стабилизация, Strike-метр), экспедиции (отправка/возврат, последствия,
протагонист-защита, айронмен, дроп лута в сташ), способности (гейт скила, AP/КД,
все 12 активок, ловушки), перки, скрытые шкалы (тик/полосы, инциденты и резолв
позициями, кризисы, пороговые всплески, Готовность), совет и фракции (цена/КД
действий, эффекты по системам, доход инвестиции, полосы отношений, соц-последствия),
лут/гир/крафт (редкость множит роллы, экипировка в агрегаторе, именной прок в бою,
крафт-апгрейд за компонент), данжи (push-your-luck: генерация комнат, банк на
экстракте, вайп губит незабанкованное) + квесты (ветвление проверок, телеграф
обходимых леталок, последствия выбора и реакции лояльности, награды, источники,
дублёры спайна) + драма ростера (ценностные связи, рябь от смерти/предательства
с ограждением от каскада, предательство-в-босса с возвратом гира).

## Что уже сделано (фундамент под GDD v6)

- **Модель персонажа — три независимые оси:** 4 атрибута (почти статичны) + 10 скилов
  (растут за очки, классов нет, респека нет) + трейты-слоты; плюс **отдельный вечный
  трек шрамов** (несбрасываемы, слоты не занимают).
- **Единый агрегатор модификаторов** («один эффект — одна система») + производные
  статы из атрибутов (мелкие числа: HP 6–20, AP 8–10).
- **Детерминированные проверки** (скил ≥ порога; лучший среди присутствующих;
  соц-проверки добирают контекстный атрибут под подход).
- **База:** позиции/назначения (конечный автомат напарника), петля времени —
  лечение в днях с ускорением от медика, стройка в 5 стадий, пассивный рост населения.
- **Экономика:** золото + строительный + крафтовый компонент (источник — вылазки;
  база материалы не производит).
- **Тактический бой (WL3-ядро):** сетка с направленными укрытиями (фланкирование
  само собой) и линией обзора, гибкий пул AP, индивидуальная инициатива вперемешку,
  надёжный % (граза ≤15% → 50% урона, ≥85% не сливается, Strike-метр), плоская
  броня + пробитие/Шред отдельно от типов урона (резист/уязвимость), состояния
  (Подавление/Кровотечение/Поджог; Воля сокращает), даун + окно на спасение со
  стабилизацией медиком, бестиарий «роль × семейство × профиль» (4 роли) и
  воспроизводимая демо-стычка 4×6.
- **Экспедиции (связка база ↔ бой):** отправка снимает напарников с позиций,
  путешествие двигает календарь (дома тикают лечение и стройки), исход боя
  возвращается в ростер — смерть насовсем, ранения тирами + вечные шрамы, XP за
  победу; лут банкуется только при победе. Протагонист в обычном режиме защищён
  (только даунится), в айронмене его гибель = game over.
- **Способности и перки:** 12 отчётливых активок на эффект-примитивах (по 3 на
  боевой скил: Очередь/Подавляющий огонь/Метка, Рывок/Подсечка/Вспороть,
  Перегруппировка/Командный рывок/Очнись! + Перевязка/Шоковый разряд/Ловушка),
  гейт порогом скила, AP + кулдауны; враги берут активки из того же пула.
  Перки — пассивные бонусы, автооткрытие по порогам скилов. Метка и Сбит-с-ног
  достроены до механики (6 из 7 состояний живые).
- **Скрытые шкалы (Эпик 11):** «Напряжение» — фоновый тик от тира города (мягкий),
  скрытые дельты квестовых выборов, инциденты по весам с серьёзностью по полосе
  (Calm→Critical), резолв занятой позицией с релевантным скилом (пусто → худший
  исход), непредотвратимые кризисы (отток населения / гибель напарника — не
  протагониста / враждебная группировка), одноразовые пороговые всплески.
  «Готовность» — копилка к финалу. Наружу — только полосы и амбиент-реплики,
  чисел нет.
- **Совет и фракции (Эпики 8.4/10):** 6 действий совета с КД и ценой (золото/
  влияние) — Облава/Указ/Дипломатия/Инвестиция/Подготовка/Снаряжение, бьющие по
  разным системам; несколько фракций с полосами отношения + репутация города +
  влияние; единая регистрация соц-последствий (один выбор двигает фракции +
  репутацию + скрытую Напругу + флаги). Наружу — полосы, без чисел.
- **Лут, гир, крафт (Эпик 6):** предметы (ItemDefinition/Instance) по слотам
  (оружие/броня/аксессуар); гир крутит числа через единый агрегатор (Source = Gear);
  гибрид-лут (Вариант Б: редкость множит магнитуду роллов); именные предметы
  фиксированы с уникальным эффектом (именная пушка прокает Кровотечение в бою);
  крафт-апгрейд редкости за крафтовый компонент.
- **Данжи (push-your-luck, Эпик 12):** процедурные комнаты (бой/схрон/проверка/
  событие), петля «экстракт или глубже», банк только на экстракте, эскалация
  угрозы; источник материалов и рандом-лута (squad-loop кормит settlement-loop).
- **Квесты и сюжетные миссии (Эпики 13–14):** авторские многоэтапные миссии с
  ветвлением (проверки/выборы/бой/исход); честные проверки (телеграф **обходимых**
  леталок, утилита soft-fail → альтернатива); последствия через единую регистрацию
  соц-последствий + **видимая рябь лояльности**; награды (XP/золото/именные); квесты
  из разных источников (вкл. инциденты Напряжения); устойчивость спайна к смерти
  (цепочка дублёров) + минимальная скрытая лояльность напарников.
- **Напарники: драма ростера (Эпик 9, ядро):** ценностные связи по тегам трейтов
  (общая ценность → сближает, противоположная → ссорит); рябь лояльности от
  смерти/предательства по связям с **ограждением от каскада** (одна смерть не
  рушит весь ростер); уход в антагонисты со своим гиром и уровнями → встреча
  боссом → возврат гира убийством; минимальный баентер.
- **Баланс data-driven** (`BalanceConfig` + `BalanceConfigAsset`), **179 EditMode-тестов**.
