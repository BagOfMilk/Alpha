# Alpha — Base Builder RPG (Unity)

Тактическая RPG со строительством базы. Бой в духе **XCOM** (сетка, укрытия,
очки действий, % попадания). Между боями — управление базой: напарники, совет,
поселение, производство ресурсов, прокачка; вылазки в процедурные подземелья
(«Дажи») за лутом и сюжетом.

> Этот репозиторий — **полноценный Unity-проект**. Код игровой логики и баланса
> написан на чистом C# (папка `Assets/_Project/Scripts/Core`), чтобы его было
> легко читать, тестировать и крутить по цифрам без запуска движка.

---

## Как открыть проект (с компьютера)

Сейчас тебе **ничего устанавливать не нужно** — всё лежит в GitHub. Когда сядешь
за компьютер:

1. Установи **Unity Hub** → https://unity.com/download
2. В Unity Hub поставь **Unity 6.4** (версия `6000.4.10f1`). Точную версию проект
   подскажет сам — Hub предложит её при открытии.
3. Склонируй репозиторий (или скачай ZIP) и в Unity Hub нажми **Add → Add project
   from disk**, выбери папку с проектом.
4. Открой проект. Unity сам сгенерирует папки `Library/`, `.csproj` и т.п.
   (они в `.gitignore` и в репозиторий не попадают — это нормально).

## Как увидеть, что всё работает

Без интерфейса, прямо в редакторе:

1. В сцене создай пустой объект: **GameObject → Create Empty**.
2. В инспекторе нажми **Add Component** и добавь `Base Game Demo`.
3. Нажми **Play**. В консоли (**Window → General → Console**) появится:
   - стартовая расстановка напарников по слотам базы,
   - отчёт по каждому игровому дню (что произведено, кто получил уровень),
   - итоговый баланс ресурсов.

Это «живая спецификация» механики базы — на ней удобно сверять баланс.

## Тесты

Открой **Window → General → Test Runner → EditMode → Run All**. Тесты проверяют
математику прокачки, распределение очков характеристик и цикл производства базы.

## Структура

```
Assets/
  _Project/
    Scripts/
      Core/            // чистый C# — вся игровая логика и баланс (без UnityEngine)
        Stats/         // характеристики (StatType, StatBlock)
        Characters/    // архетипы, напарники, прокачка, ростер
        Base/          // слоты назначений, секции, производство, цикл базы
        Economy/       // ресурсы и кошелёк базы
        Balance/       // конфиг баланса и формулы прокачки
        DefaultContent.cs  // стартовые архетипы и слоты (затравка контента)
      Gameplay/        // тонкие обёртки Unity (ScriptableObject, MonoBehaviour-демо)
  Tests/EditMode/      // юнит-тесты на логику и баланс
docs/
  DESIGN.md            // дизайн механик и дорожная карта
  BALANCE.md           // формулы и «крутилки» баланса
```

## Что уже сделано (итерация 1)

- **Ядро RPG:** характеристики, статблоки, кривые опыта/уровней, рост статов по
  архетипу.
- **База и напарники (вертикальный срез):** секции (Совет, Поселение,
  Мастерская, Лаборатория, Лазарет, Склад, Казарма, Разведпост), слоты
  назначений, назначение/перевод напарников, производство ресурсов и пассивных
  бонусов за цикл, ролевой опыт за работу, лечение раненых, расход еды.
- **Баланс data-driven:** все числа собраны в `BalanceConfig` и доступны для
  правки в инспекторе через `BalanceConfigAsset`.
