# Alpha — Base Builder RPG (Unity)

Тактична RPG з будівництвом бази. Бій у дусі **XCOM** (сітка, укриття,
очки дій, % влучання). Між боями — керування базою: напарники, рада,
поселення, виробництво ресурсів, прокачування; вилазки в процедурні підземелля
(«Дажі») за лутом і сюжетом.

> Цей репозиторій — **повноцінний Unity-проєкт**. Код ігрової логіки та балансу
> написаний на чистому C# (папка `Assets/_Project/Scripts/Core`), щоб його було
> легко читати, тестувати і крутити по цифрах без запуску рушія.

---

## Як відкрити проєкт (з комп'ютера)

Зараз тобі **нічого встановлювати не потрібно** — все лежить у GitHub. Коли сядеш
за комп'ютер:

1. Встанови **Unity Hub** → https://unity.com/download
2. В Unity Hub постав **Unity 6.4** (версія `6000.4.10f1`). Точну версію проєкт
   підкаже сам — Hub запропонує її при відкритті.
3. Клонуй репозиторій (або завантаж ZIP) і в Unity Hub натисни **Add → Add project
   from disk**, вибери папку з проєктом.
4. Відкрий проєкт. Unity сам згенерує папки `Library/`, `.csproj` тощо.
   (вони в `.gitignore` і в репозиторій не потрапляють — це нормально).

## Як побачити, що все працює

Без інтерфейсу, прямо в редакторі:

1. У сцені створи порожній об'єкт: **GameObject → Create Empty**.
2. В інспекторі натисни **Add Component** і додай `Base Game Demo`.
3. Натисни **Play**. У консолі (**Window → General → Console**) з'явиться:
   - стартова розстановка напарників по слотах бази,
   - звіт по кожному ігровому дню (що вироблено, хто отримав рівень),
   - підсумковий баланс ресурсів.

Це «жива специфікація» механіки бази — на ній зручно звіряти баланс.

## Тести

Відкрий **Window → General → Test Runner → EditMode → Run All**. Тести перевіряють
математику прокачування, розподіл очок характеристик і цикл виробництва бази.

## Структура

```
Assets/
  _Project/
    Scripts/
      Core/            // чистий C# — вся ігрова логіка та баланс (без UnityEngine)
        Stats/         // характеристики (StatType, StatBlock)
        Characters/    // архетипи, напарники, прокачування, ростер
        Base/          // слоти призначень, секції, виробництво, цикл бази
        Economy/       // ресурси та гаманець бази
        Balance/       // конфіг балансу та формули прокачування
        DefaultContent.cs  // стартові архетипи та слоти (затравка контенту)
      Gameplay/        // тонкі обгортки Unity (ScriptableObject, MonoBehaviour-демо)
  Tests/EditMode/      // юніт-тести на логіку та баланс
docs/
  DESIGN.md            // дизайн механік і дорожня карта
  BALANCE.md           // формули та «крутилки» балансу
```

## Що вже зроблено (ітерація 1)

- **Ядро RPG:** характеристики, статблоки, криві досвіду/рівнів, зростання статів за
  архетипом.
- **База і напарники (вертикальний зріз):** секції (Рада, Поселення,
  Майстерня, Лабораторія, Лазарет, Склад, Казарма, Розвідпост), слоти
  призначень, призначення/переведення напарників, виробництво ресурсів і пасивних
  бонусів за цикл, рольовий досвід за роботу, лікування поранених, витрата їжі.
- **Баланс data-driven:** усі числа зібрані в `BalanceConfig` і доступні для
  правки в інспекторі через `BalanceConfigAsset`.
