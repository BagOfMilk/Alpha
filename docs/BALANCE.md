# Баланс — формулы и «крутилки»

Все числа собраны в `BalanceConfig` (чистый C#) и доступны в инспекторе через
`BalanceConfigAsset` (он держит `BalanceConfig` как вложенное сериализуемое поле —
любое новое поле появляется в инспекторе само). Меняешь там — меняется вся игра.
Числа — стартовые **ПЛЕЙСХОЛДЕРЫ** из Приложения Б GDD; тюнятся в плейтесте.

## 1. Прокачка / опыт

**Порог опыта до следующего уровня:**
```
XpToNext(level) = round( XpBase * level ^ XpExponent )
```
Старт: `XpBase = 100`, `XpExponent = 1.5`, `MaxLevel = 20`.

| level | XpToNext |
|------:|---------:|
| 1 | 100 |
| 2 | 283 |
| 3 | 520 |
| 5 | 1118 |
| 10 | 3162 |

**Очки скилов за уровень:** `SkillPointsPerLevel = 3` — кладутся в нераспределённый
пул (`Companion.UnspentSkillPoints`), игрок тратит вручную (`SpendSkillPoint`).
Классов нет, **респека нет** (понижать скилы в геймплее нельзя).

## 2. Производные из атрибутов

Считаются в `DerivedStatCalculator` как БАЗА, затем сворачиваются с модификаторами
(гир/трейты/шрамы/состояния) в `ModifierAggregator`. Мелкие числа — намеренно.

| Производный стат | Формула | Дефолтные коэффициенты |
|---|---|---|
| MaxHp | `HpBase + Сила·HpPerStrength` | 4 + Сила·2 → **6…20** |
| ActionPoints | `round(ApBase + Ловкость·ApPerAgility)` | 8 + Ловк·0.2 → **8…10** |
| Accuracy | `AccuracyBase + Ловкость·AccuracyPerAgility` | 50 + Ловк·2 |
| Defense | `DefenseBase + Ловкость·DefensePerAgility` | 0 + Ловк·1 |
| Initiative | `Ловкость·.. + Смекалка·..` | Ловк·1 + Смек·1 |
| Carry | `CarryBase + Сила·CarryPerStrength` | 4 + Сила·1 |
| CritChance | `CritBase + Ловкость·CritPerAgility` | 5 + Ловк·1 |
| Armor | база 0 | от гира (модификатор) |
| Resolve | `Воля·ResolvePerWill` | Воля·1 (сокращает длительность состояний) |

> **Итог модификатора** = `round( (база + Σ flat) × (1 + Σ percent/100) )`, не ниже нуля.
> Каждый источник учитывается один раз — нет двойного счёта (US-18.2).

## 3. Бой (WL3) — реализованные формулы (`Core.Combat`)

**Шанс попадания** (`HitChanceCalculator.Compute`):
```
шанс = Точность_атакующего                  // производная + скил оружия × AccuracyPerWeaponSkill (3)
     − Защита_цели
     − укрытие        // полу −20 / полное −40; МИЛИ ИГНОРИРУЕТ укрытие
     − дистанция      // (дистанция − оптимал оружия) × DistancePenaltyPerTile (5), только дальше оптимала
     − Подавление     // SuppressionAccuracyPenalty (15), если атакующий подавлен
кламп: HitChanceMin (1) .. HitChanceMax (99)
```
Укрытие **направленное**: считается по сторонам тайла защитника, обращённым к
атакующему (по диагонали — лучшее из двух). Зашёл с открытой стороны = фланг,
штрафа нет.

**Ролл** (`HitChanceCalculator.Roll`, d100):
```
ролл ≤ шанс                                  → попадание
ролл − шанс ≤ GrazeThresholdPercent (15)     → граза (50% урона)
иначе, если шанс ≥ HighHitNoFullMiss (85)    → граза (полностью слиться нельзя)
иначе                                        → промах
```

**Конвейер урона** (`DamageResolver`, порядок зафиксирован):
```
1. ролл урона:   крит (d100 ≤ крит-шанс; не на гразе) → DamageMax + CritDamageBonus
                 иначе → rand(DamageMin..DamageMax)
2. × множитель типа урона по цели    // резист ×0.5–0.75, уязвимость ×1.25–1.5
3. − плоская броня                    // max(0, броня − Шред − пробитие оружия)
4. граза → × GrazePartialPercent (50%)
5. не ниже 0
```
**DoT обходят броню** (в мелких числах флэт-броня обнуляла бы тик), но множатся
типом: Кровотечение — True (без множителя), Поджог — огонь, Яд — токсин.

**Strike-метр:** +`StrikePerHit` (1) за полное попадание; при `StrikeGuaranteeAt`
(3) можно потратить на гарантированный удар (метр в 0, без накопления за этот удар).

**Состояния:** наложение гарантированное; длительность = max(1, база −
Resolve / ResolvePerStatusTurnReduction (3)); повтор освежает (не стакает).
DoT тикают в начале хода носителя, длительность −1 в конце его хода.
Подавление: −точность (15) + движение × SuppressionMoveCostMultiplier (1.5, вверх), длительность 1.
Метка: +MarkedHitBonus (10) к шансу по цели. Сбит с ног: −KnockdownDefensePenalty (10)
к защите (не ниже 0); в начале своего хода встаёт за StandUpApCost (2).

**Способности** (AP / КД / дальность — стартовые числа из DefaultContent):
```
Стрелковое: Очередь 6/2/8 (2 выстрела по −10 точности) · Подавляющий огонь 4/2/8 (удар −10 + Подавление) · Метка 2/1/10
Ближнее:    Рывок 4/2/4 (дэш вплотную + удар) · Подсечка 4/2/1 (удар + Сбит-с-ног) · Вспороть 3/2/1 (удар + Кровотечение)
Тактика:    Перегруппировка 3/3/6 (+4 AP союзнику) · Командный рывок 2/2/6 (переставить на ≤3) · Очнись! 2/2/6 (снять контроль)
Утилита:    Перевязка 4/2/1 (хил 4) · Шоковый разряд 3/2/5 (3 энергии + Шред 1) · Ловушка 3/3/3 (мина 3 + Кровотечение)
```
КД тикает в начале СВОЕГО хода. Флэт-урон способностей/ловушек: ×тип − броня (без крита/гразы).

**Перки** (порог скила → пассив): Стрелковое 2/4 → +5 точности / +5 крита;
Ближнее 2/4 → +2 HP / +1 броня; Тактика 2/4 → +1 AP / +3 Resolve.
Открываются автоматически (`RefreshPerks`), модификаторы — через единый агрегатор.

**Движение:** BFS по ортогональным соседям, MoveApCostPerTile (1).
**Стабилизация дауна:** смежность (Чебышёв 1), скил Медицины ≥ 1,
StabilizeApCost (4), детерминирована. Окно дауна: DownWindowTurns (2) —
тикает в начале хода упавшего; вышло → смерть насовсем.

Полоса значений: AP 8–10; атака 3–4 AP; HP 6–20; урон 2–8; броня 0–2;
DoT 2 урона × 3 хода; отряд из 4.

## 3.1 Экспедиции (связка база ↔ бой)

```
Ironman = false               // айронмен: протагонист теряет сюжетную защиту (US-4.4)
LightInjuryHpFraction = 0.5   // HP ≤ 50% после победы → Лёгкое ранение (без шрама)
XpPerExpeditionVictory = 80   // XP каждому выжившему за победную вылазку
```
Тиры последствий: погиб в бою → смерть насовсем; Stabilized/Downed на конец боя →
**Серьёзное** + вечный шрам (на поражении — **Критическое**); дни пути — в
`ExpeditionPlan` (туда/обратно), лечение тикает уже по дороге домой. Лут
банкуется только при победе.

## 4. Ранения и восстановление

- **3 тира → дни лечения:** Лёгкое 2, Серьёзное 5, Критическое 10
  (`InjuryDaysLight/Serious/Critical`). Серьёзное+ присваивает вечный шрам.
- **Скорость лечения за день:**
```
recovery/день = NaturalRecoveryPerDay (1)
              + [Лазарет укомплектован?] ( InfirmaryRecoveryPerDay (1)
                                          + Медицина_медика · MedicRecoveryPerSkillPoint (0.2) )
```
Чем меньше `NaturalRecoveryPerDay`, тем дороже каждая рана и важнее Лазарет/медик.

## 4.1 Скрытые шкалы (Эпик 11)

**Напряжение** (0..100, игроку не показывается — только полосы/сигналы):
```
TensionPerDayPerTier = 0.2     // фоновый тик: тир города × N в день (декада простоя ≈ +2)
Полосы: Uneasy 25 · Tense 50 · Critical 75
IncidentChanceBase = 4         // % в день при нуле
IncidentChancePerTension = 0.4 // T=50 → 24%/день; T=75 → 34%/день
```
Дельты инцидентов (контент): мелкие −3/+4 (порог 2), организованные −5..6/+8
(порог 4), кризисы −6..8/+10..12 (порог 6). Серьёзность по полосе: Calm — мелкие;
Tense + организованная преступность; Critical + кризисы. Кризис-эффекты
непредотвратимы: отток `CrisisExodusPopulation = 3`, гибель напарника (не
протагонист), враждебная группировка. Пороговый всплеск: «Удар по своим» на 75
(одноразовый). Резолв: занятая позиция с релевантным скилом, проверка US-2.6;
пусто → худший исход.

**Готовность** (скрыта): `ReadinessPerPreparation = 10` (действие совета),
`ReadinessPerFortification = 15` (Укрепления); полосы Braced 25 / Fortified 60.

## 4.2 Совет и фракции (Эпики 8.4/10)

Числа действий — в данных (`CouncilActionDefinition`), не в `BalanceConfig`
(как у способностей). Стартовый сид (`DefaultCouncil`, ПЛЕЙСХОЛДЕРЫ):
```
Облава        20 зол + 1 вл, КД 6 → −12 Напряжения; Гарнизон +6, Вольные −8
Указ          1 вл,         КД 8 → Торговцы +8, Община −6 (размен)
Дипломатия    2 вл,         КД 6 → +10 выбранной фракции, +2 репутации
Инвестиция    40 зол,       КД 8 → +8 золота/день × 10 дней (40 → 80)
Подготовка    15 зол + 1 вл,КД 6 → +10 Готовности
Снаряжение    25 зол,       КД 5 → следующей вылазке +10 точности, +30 золота лута
```
**Фракции** (`FactionStanding`, −100..+100, старт 0): полосы
Hostile ≤ −50 < Cold < Neutral (−15..15) < Warm < Allied ≥ 50.
**Репутация города** (0..100): Unknown < Known (20) < Respected (50) < Renowned (80).
**Влияние** — целочисленная валюта совета (копится делами/квестами, US-10.4).
Гейтинг контента — `AtLeast(faction, band)`; критический путь за одной фракцией
не запирается (US-10.1). КД и доход инвестиции тикаются `Council.TickDays`.

## 4.3 Лут, гир, крафт (Эпик 6)

Числа предметов — в данных (`ItemDefinition`), не в `BalanceConfig`. Вариант Б:
```
Магнитуда роллов × редкость: Common ×1.0 · Uncommon ×1.5 · Rare ×2.0 · Epic ×2.5
Веса дропа (LootTable по умолч.): 60 / 25 / 12 / 3 (Common..Epic)
Именные: фикс (роллов не катают, магнитудой не множатся) + уникальный эффект.
Крафт-апгрейд: тратит крафтовый компонент, поднимает редкость на тир (пере-ролл).
```
Сид-контент (`DefaultItems`): дроп-пул — Сборная винтовка (Точность 2–5), Бронежилет
(Броня 1–2, HP 1–3), Прицел (Точность 3–6, Крит 2–4); именные — «Вдоводел» (Epic,
прок Кровотечения) и «Эгида» (Rare, Броня/HP + сигнатурный +Resolve).
Гир сходится в единый агрегатор производных (Source = Gear).

## 4.4 Данжи — push-your-luck (Эпик 12)

Тюнинг в `DungeonGenerator` (не в BalanceConfig), чтобы данж был самодостаточен:
```
Веса комнат: Combat 50 / Loot 25 / Check 15 / Event 10
ThreatPerDepth = 2 (за уход вглубь) · EliteThreatThreshold = 6 (→ элита/подкрепление)
Враги: count = min(2 + глубина/2, 6); элита добавляет +1
Лут (множится глубиной): бой gold = 8×глуб; схрон gold = 12×глуб + предмет(ы)
Проверка: Взлом, порог 2 + глубина/3; успех → 10×глуб; провал → +угроза (мягкий сетбэк)
```
**Банк только при экстракте**; вайп губит незабанкованное. Материалы (строит./крафт.)
капают с боёв и схронов — основной их источник (squad-loop кормит settlement-loop).

## 5. База: население и стройка

```
PopulationGrowthPerDay = 0.25     // пассивный рост (ускоряется Таверной/жильём)
ConstructionSmallDays  = 4         // малая стройка 3–5 дней
ConstructionLargeDays  = 10        // крупная 8–12 дней
ConstructionStages     = 5         // 5 визуальных стадий по таймеру
```
**Материалы базой не производятся** — золото и оба компонента приходят только с
вылазок/квестов (squad-loop кормит settlement-loop).

## 6. Создание персонажа / трейты

```
TraitSlots = 4   // фикс число активных трейтов; новый сверх лимита требует вытеснения
```
Шрамы слоты НЕ занимают и несбрасываемы.

## 7. Как менять баланс на практике

1. **В коде/тестах:** правь дефолты в `BalanceConfig.cs`, гоняй EditMode-тесты
   (`Window → General → Test Runner`) — они ловят регрессии формул.
2. **В Unity:** `Create → Alpha → Balance Config`, положи ассет на `BaseGameDemo`,
   крути числа в инспекторе, жми Play, смотри лист персонажа и петлю времени в консоли.
3. **Пресеты сложности:** несколько `BalanceConfigAsset` (Easy/Normal/Hard).
