## 2. Як проганяю (мій Unity-слот, лише за «можна» ПМ)
1. `git merge` магістралі в мою гілку (лише за дозволом власника на коміт злиття) → прохід компіляції → `BuildPlayerShow`
   (без Development; Burst — як дозволить P0-3) → одна тека копії в scratchpad, ASCII-шлях.
2. Запуск без ShellExecute, `mute_loop.ps1` + ворота звуку: `-ring-shots <тека> -ring-seed 7 -ring-shot-seasons 3
   -ring-shot-grow -ring-shot-speed 3 -ring-shot-limit 4000`, 1600×900. Другий прогін — інший сід (11) для іншого ростеру.
3. Розбір: підсумкові рядки §1 + усі рядки `фаз-тест:` / `контакт:` / `режисер:` з кліпом і миттю → таблиця
   «кліп → вада → скільки разів → найгірше» — кожен рядок адресовано власнику кліпа (Кліпи-1…4) або режисеру (Бій).
4. Очима: аркуші `beat_*` (накриття, больові, фінішери, кидки) + по 3 найгірші миті кожної мірки — кадри з
   `-ring-demo -ring-demo-every 0.1` на тому кліпі, коли демо вміє брати прийом (`RingDemoScript`, Ф2).
5. Звіт `docs/ring/playtest_<дата>_fbx<версія>.md` у трьох розділах + промпт ПМ із вадами. Повтор — на кожен новий FBX,
   з порівнянням «було / стало» за шістьма мірками.

## 3. Чого бракує — промпт ПМ
- **Г1 (Бій, `RingStage3D.DirectorReport` / `RingMatchDirector`):** лічильники режисера скидаються на початку матчу, а бот
  пише `PlayedReport` раз наприкінці — у прогоні 3 сезонів видно лише останній матч. Потрібні **суми за весь прогін**
  (як `RingStageWatch`), або рядок `режисер за матч` у лог після кожного матчу — я підсумую.
- **Г2 (власник `RingStageWatch` — «Изучение»):** поріг ковзання 8 см → додати другий рівень **2 см** (М1), не прибираючи 8 см
  (щоб «було / стало» з pass3 лишалось порівнянним): `ковзання понад 0.02 м — N; понад 0.08 м — M`. Окремо — ковзання
  рефері (`Ref_*`) рахувати окремим числом: у pass3 це 1,4–2,3 м і воно глушить вади борців.
- **Г3 («Изучение», після злиття 6a2b395 у бій):** три рядки підключення `RingContactWatch` у `RingStage3D` (текст — у ZONES,
  розділ «План кадрів приймання М1»). Після злиття «Изучения» — перевести масштаб тіла на публічний `stage.BodyScale(a)`
  (моя зона).
- **Г4 (Бій):** у підсумку кліпів — перелік підстановок **з назвами** (`бракує …` × кількість), не лише число: інакше Кліпам
  не видно, який кліп робити першим.
- **Г5 (Бій / Изучение):** телепорти «під склейкою» — показувати, на якому кліпі (зараз рахується лише число) — після Ф2
  склейок стане більше, і там можуть ховатися справжні стрибки.
