## Що зробити
1. **Титул (ліва колонка, відступ 5 % від країв, зверху):**
   - **Вордмарк = канатна рамка + ЖИВИЙ текст.** Рамка — `Assets/Art/Ring/Brand/rope_frame_1040.png` (стійки з подушками й три канати, літер немає) або ті самі прямокутники з `docs/ring/design/brand/rope_frame.svg`, намальовані `Painter2D`. «РИНГ» — Label у ролі display, Black, ВЕЛИКІ, нахил (синтетичний italic), колір `Gold`, чорний ореол 6 px (`Bg`) поверх канатів. Ширина логотипа ≈ 34 % ширини екрана; текст — через ключ, **не** в картинці.
   - Підзаголовок «Місцева федерація · один борець · сезон за сезоном»: display Bold, **15 px, розрідка 0,2 em, `TextDim`** (ключ `ui.title.sub*`), ВЕЛИКІ.
   - Кнопки — афішні пластини (як на дошці): ширина 450, висота 60, правий край зрізаний під 12° (`Painter2D`), ліва смужка 10 px; номер 22 px 70 % прозорості; текст display ExtraBold 27, ВЕЛИКІ. Головна («Нова кар'єра» або «Продовжити») — заливка `Gold`, текст `Bg`, смужка `Crimson`; решта — `Panel`, смужка `TextDim`; «Вийти» — смужка `Signal`. Фокус/наведення — заливка `Hover`.
   - Куток справа знизу: «Наступне шоу · Субота · 19:00» (display 17 / 55 px, `TextDim`/`Text`) — необов'язково, але дає життя екрану.
   - Прибрати «Development Build» зі збірки для показу (B00 §3).
2. **Вступ/титантрон (`RingShow.cs`):** «РИНГ» — вордмарк із рамкою (не 110 px білим), підпис — `Gold`; без `#FFD966`. Кольори іскор/PAR — з `RingTheme` (B00).
3. **Пауза (Esc) — новий оверлей:** затемнення `Scrim` α `AlphaScrim`, по центру три пластини («Продовжити», «Налаштування» — повний екран/вікно, «На титул»); заголовок «ПАУЗА» display 62 px `Gold` у нахиленій пластині. Не додавати нових механік — лише показ.
