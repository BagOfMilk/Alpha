# «Ринг» — аудит відчуття матчу й лупу (06.11.2026)

Доручення власника: прибрати те, через що грати прикро («боляче»), і додати те, що дає радість («не весело»).
Рішення власника (2d6, три ступені, шанс видно до кидка, гібрид букера, один борець) не змінювались.
Кліпи прийомів не чіпались: вони в зоні іншої сесії. Тут змінено лише камеру, світло, зал, рефері, екрани й режисер.

## 1. Симуляція відчуття — 1000 матчів кар'єри

Охоронець — `Assets/Tests/EditMode/Ring/MatchFeelTests.cs`. Гравця й суперника веде той самий ШІ, як у `FinisherReachTests`. Тиждень 1, зерна 5000–5999.

| Що | Число |
|---|---|
| Кидки гравця: чистий / частково / провал | 39 % / 44 % / 17 % (7158 кидків) |
| Раундів на матч | 5,7 |
| Матчів з near-fall «на два» | 35 % (гравець вирвався 240 разів, суперник 318) |
| Найдовша серія провалів | 6 за весь замір; у середньому найдовша за матч — 0,9 |
| До першого попу залу | 3,8 дії гравця; без жодного попу — 11 % матчів |
| Перемог / поразок / нічиїх | 751 / 249 / 0 |
| Фінішер влучний | у 532 матчах |

Поп — це подія, на яку зал реагує вибухом: вирвався «на два», влучний фінішер або ажіотаж +2 і більше за раз.

**Висновок щодо R7:** у формулюванні «чистих успіхів немає» гіпотезу спростовано. Чистий успіх — 39 % кидків. Біда не в
ймовірностях, а в подачі: чистий успіх виглядав так само, як «частково», бо обидва закінчувались рядком журналу.
Механіку не змінювали.

**Для рішення власника:** у першому тижні гравець виграє 75 % матчів. Це може бути задумом («новачок проти
слабших»), а може бути занадто легко. Пропоную поміряти так само на тижнях 2–4 і на великому шоу, перш ніж щось міняти.

### 1.1. Перемоги по сезону й тижню (замір 06.11.2026, «Так, поміряй»)

Методика: 300 кар'єр по три сезони. Дії тижня й розвиток веде звичайний бот (`CareerBot`), кожен матч за обидві сторони грає
однаковий ШІ, титульний шанс береться завжди. Замір — `MatchFeelTests.WinRates_ByWeek_FeudAndTitle`.

| | Сезон 1 | Сезон 2 | Сезон 3 |
|---|---|---|---|
| Тижні 1–3 (щотижневе шоу) | 69–76 % | 70–79 % | 91–95 % |
| Велике шоу ворожнечі (Молот) | 60 % | 89 % | 98 % |
| Титульний матч (шанс — у 872 з 900 сезонів) | 82 % | | |

**Що це означає.** Крива складності йде вниз: гравець росте (очки розвитку, перки, прийоми), а суперники ні. Атрибути NPC
задані в `career_roster.json` і не змінюються, букер не підбирає сильніших суперників за місцем у картці. З другого сезону
напруги вже немає: ворожнеча з Молотом виграється в 9 з 10 матчів, у третьому — майже завжди. Титульний шанс випадає
майже щосезону (довіра букера 4+ досягається легко), і титул береться у 82 % випадків. Перемога перестає бути новиною,
а «програти й стати зіркою» — недосяжним.

**Це зміна механіки, тож рішення за вами.** Варіанти:

1. **Суперник за місцем у картці (рекомендую).** Що вище гравець у картці й популярніший, то сильніших суперників ставить
   букер: +1 до атрибута-основи ґіміка NPC на кожен щабель картки, Молот у другому й третьому сезоні — +1 і +2. Це
   рестлінгова логіка («виріс — дали сильніших»), і вона тримає криву, хоч би як гравець качався.
2. **Ростер росте щосезону.** Усі NPC отримують +1 атрибут за сезон. Просто, але слабо пов'язано з історією гравця.
3. **Лишити як є.** Сприймати це як «влада заробленого»: перший сезон — боротьба, далі — домінування. Тоді напругу
   мусять давати інші джерела (травми, ворожнечі, федерації), а їх в ітерації 1 мало.

Ціль для варіанта 1 (пропозиція): щотижневі матчі — 55–65 %, ворожнеча — ~50 %, титул — 35–45 %, у кожному сезоні.
Після рішення ці межі стануть охоронцем у тому самому тесті.

### 1.2. Рішення власника й результат (06.11.2026: «1: за місцем у картці»)

**Що зроблено** (`CareerRules` — розділ «сила суперника», `ShowBooker.Strengthen`, `CareerSession.RivalStepsNow/PlayerGrowth`):

- **Щабель сили** — +1 атрибут суперникові. Черга: атрибут фінішера, Витривалість, Техніка, Сила. Понад межу +3 щаблі
  переходять у стартовий імпульс, «Вирватися», «залізну щелепу» й жетони реверсу. Спритність і Харизму пропущено, бо
  замір показав: щаблі туди майже не додають сили.
- **Скільки щаблів:**
  - база за місцем у картці (масив `RivalStepsByPosition`);
  - плюс ріст гравця. Ріст — це куплені атрибути понад базу ґіміка, перки (кожні два — одиниця) й вивчені прийоми,
    у щаблі перераховано опукло;
  - Молот: +2 за кожен зіграний матч ворожнечі;
  - титул: 5 + ріст.
- **Картка вечора** показує заздалегідь: «У формі: сильніший на N — суперники ростуть разом із тобою».
- **Сейв не змінено:** усе рахується з того, що вже зберігається.

**Що показав замір і чому так.** Перша спроба — лише за місцем у картці, від +1 до +4. Вийшло: s2 40–45 %, s3 67–78 %.
Місце насичується на мейн-івенті, а гравець росте далі. До того ж мейн-івент гравець отримує вже в другому сезоні,
коли ще не виріс. Додатковий щабель за мейн-івент душив другий сезон (44–49 %).

**Рішення власника 06.11.2026: «Повернути»** надбавку за мейн-івент. База за місцем — `{1, 1, 1, 2}`: відкривання, середина
й передостанній — +1, мейн-івент — +2. Провал другого сезону знято порогом росту: `RivalGrowthOffset` 16 → 21, тобто
перші одиниці росту ще не підсилюють суперника. Окрім надбавки, місце діє й через вибір суперника: вище в картці букер
ставить NPC вищого рангу.

**Результат** (300 кар'єр по три сезони):

| | Сезон 1 | Сезон 2 | Сезон 3 |
|---|---|---|---|
| Щотижневе шоу | 61–73 % | 52–54 % | 56–65 % |
| Молот | 50 % | 60 % | 57 % |
| Титул | 41 % | | |

Охоронець — `MatchFeelTests.WinRates_ByWeek_FeudAndTitle`, з межами із запасом на шум:
- щотижневі 45–75 % у кожному сезоні;
- Молот 38–68 %;
- титул 30–52 %.

Тиждень 1 першого сезону (73 %) лишився трохи легшим: це вхід новачка.

### 1.3. Піки сили 70–80 % (рішення власника 06.11.2026: «Піки 70–80%»)

Рівна крива з §1.2 гасила прокачку: ти виріс, а виграєш не частіше. Рішення: середнє лишається в смузі, але після прокачки
й на реванші гравець відчутно сильніший. Зроблено (`CareerRules` — «сила суперника», `CareerSession.RivalStepsNow/UpdateTier/IsRematch`):

- **Сходинки.** Щотижневі суперники рівняються не на поточний ріст гравця, а на знімок, знятий на вході в щабель картки
  (`TierPos/TierGrowth` у сейві). Між підвищеннями прокачка відчувається. На новому, вищому щаблі знімок оновлюється:
  суперники знову твого рівня. На початку сезону знімок наздоганяє ріст повністю, бо на мейн-івенті вищого щабля немає.
- **Реванш.** Той, хто тебе переміг, наступного разу слабший на 2 щаблі: ти знаєш його слабкість. Букер охоче ставить
  реванш (+3 до вибору). Реванш одноразовий; програв і його — нової образи немає (`Grudges` у сейві). Картка вечора
  пише: «Реванш: він тебе вже бив — ти знаєш його слабкість».
- **Кульмінації без змін:** ворожнеча з Молотом і титул рахуються від поточного росту, тож лишаються важкими.
- **Старі сейви** читаються: «знімка ще не було», образ немає (`CareerSaveTests`).

**Замір** (300 кар'єр по три сезони):

| | Перемог |
|---|---|
| Реванш | 73 % |
| Щотижневий матч після прокачки (суперник відстає на 2+ щаблі) | 71 % |
| Відставання на 1 щабель | 58 % (звичайний розкид, не пік) |
| Щотижневі за сезонами | s1 61–73 %, s2 52–68 %, s3 68–78 % |
| Разом із великим шоу | s1 ~63 %, s2 ~60 %, s3 ~67 % |
| Молот | 49 / 60 / 52 % |
| Титул | 41 % |

Охоронець — `MatchFeelTests.WinRates_ByWeek_FeudAndTitle`:
- реванш і пік 2+ — 64–86 %;
- щотижневі — 45–75 % у кожному сезоні;
- Молот — 38–68 %;
- титул — 30–52 %.

**Відкрите.** Третій сезон щотижнево — 72 % у середньому, трохи вище за смугу 50–65 %: це майже весь мейн-івент без
вищого щабля. Спробувано мейн-івент +3: середнє падає до 70 %, але пік прокачки слабшає до 69 %. Тому лишено ваше
«Повернути» (+2). Якщо третій сезон має бути важчим, потрібна наступна сходинка після мейн-івенту: федерація вищого
рівня (`iter1_gaps.md`), а не ще одна надбавка.

## 5. Що не зроблено й чому

- **Живий звук не перевірено:** його неможливо почути з кадрів. Звук подій уже був (`RingSound`); тут лише впорядковано, коли він звучить.
- **Наведення мишею** (підказки на кнопках) не перевірено очима: бот не водить мишею.
- **Підписні фінішери, вихід напарника, перелаз через канати:** бракує кліпів у таблиці (`RingClipTable` Note). Це зона сесії анімацій.
- **Баланс тижня 1 (75 % перемог)** — питання до власника, див. §1.
