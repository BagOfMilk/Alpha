# Звук меню «Рингу» (Вхід, Завантаження, Налаштування)

Стиль — варіант «А — Енергія» (рішення власника 07.11.2026): acid-jazz / фанк-рок, упевнена
енергія «виходиш на арену». Беремо **принципи** (живий груув, яскрава секція духових,
чіткий ритм-тема), без чужих мелодій, назв і семплів. Уся музика оригінальна: один
лейтмотив у трьох варіаціях, щоб меню звучали як одна гра.

Робочі файли: `Assets/Art/Ring/Audio/Menu/` (генерує `tools/ring_audio`, див. його README).
Ліцензія — власна генерація, без атрибуції, можна публікувати й продавати.

## 1. Правила звуку меню

**Шини (Mixer):** `Master` → `Music`, `SFX`, `Voice`. Меню користується `Music` і `SFX`.

| Параметр | Значення |
|---|---|
| Музика | інтегральна гучність **-16 LUFS** (±0,5), істинний пік **≤ -1 dBTP** |
| Формат | WAV 16 біт, 48 кГц (у Unity — Vorbis; музика Streaming, SFX Decompress On Load) |
| Кросфейд між екранами | **0,8 с** (допустимо 0,5–1 с), еквіпотужний; новий екран стартує з початку петлі |
| Петлі | цілий кліп безшовний (`loop=whole-clip yes`); точка петлі = початок і кінець файлу |
| SFX | один тембр: тон Rhodes + приглушений мідний «блип» + сухий дерев'яний клац; короткі, без реверба, пік ≤ -1 dBTP |
| Стеми | рендеряться на вимогу (`--stems`); не комітяться (завеликі, відтворювані) |
| Налаштування | слайдери Music/SFX керують шинами; звук слайдера не частіше за крок значення |

**Який SFX на яку подію інтерфейсу:**

| Подія UI | Файл | Роль / характер |
|---|---|---|
| Зміна фокусу (курсор, hover, стрілки) | `ui_move` | м'який високий тик, 75 мс |
| Підтвердити, натиснути кнопку | `ui_confirm` | глухий «хіт»: низький блип + тіло, 240 мс |
| Назад, скасувати, закрити | `ui_back` | дві м'які ноти вниз, 160 мс |
| Помилка, недоступна дія | `ui_error` | дисонансний дрібний секундовий «зумер» + низький удар, 340 мс |
| Перемикач вкл/викл | `ui_toggle` | два тони вгору, 120 мс |
| Крок слайдера | `ui_slider` | дуже короткий тик, 50 мс |
| Зміна вкладки | `ui_tab` | коротка діагональна «рубка»: шумовий свист + клац, 170 мс |
| Перехід між екранами | `ui_transition` | великий свист + удар духових на F, 500 мс |
| Завантаження завершене | `ui_load_done` | арпеджіо Fm9 угору + м'які духові, 800 мс |
| Успішний вхід | `ui_login_ok` | перші чотири ноти лейтмотиву (духові + Rhodes), 1,38 с |

## 2. Лейтмотив (оригінальний)

Фа мінор (натуральний: F G Ab Bb C Db Eb; E-бекар дозволений над C7#9), 4/4, 16 кроків на
такт. Запис: `нота@крок(довжина у шістнадцятих)`; такти 1-based; C4 = 60.

```
такт 1: C5@0(3)  Eb5@3(1)  F5@4(2)  Ab5@8(2)  G5@10(1)  F5@11(3)  Eb5@14(2)
такт 2: F5@0(6)  C5@8(2)  Eb5@10(2)  Db5@12(4)
такт 3: Eb5@0(3)  F5@3(1)  Ab5@4(2)  Bb5@8(2)  Ab5@10(1)  G5@11(3)  F5@14(2)
такт 4: Bb5@0(2)  Ab5@2(2)  G5@4(4)  E5@8(2)  F5@10(6)
такт 5: акордові удари духових@2 і @6;  C6@8(2)  Bb5@10(1)  Ab5@11(1)  F5@12(4)   (відповідь)
такт 6: Ab5@0(3)  Bb5@3(1)  C6@4(4)  Eb6@8(2)  Db6@10(2)  C6@12(4)
такт 7: Bb5@0(2)  Ab5@2(2)  F5@4(4)  G5@8(2)  Ab5@10(2)  Bb5@12(4)
такт 8: C6@0(6)  Bb5@8(2)  Ab5@10(2)  G5@12(2)  E5@14(2)                            (розв'язка в такт 1)
```

**Гармонія** (цикл 4 такти, повторюється):

| Такт циклу | Акорд | Голосування |
|---|---|---|
| 1 | Fm9 | F3 Ab3 C4 Eb4 G4 |
| 2 | Dbmaj9 | Db3 F3 Ab3 C4 Eb4 |
| 3 (1-ша половина) | Bbm9 | Bb2 Db3 F3 Ab3 C4 |
| 3 (2-га половина) | Eb13 | Eb3 G3 Db4 F4 C5 |
| 4 | C7#9 | C3 E3 Bb3 Eb4 (D#4) |

Бас: корені F2, Db2, Bb1 → Eb2, C2; у такті 4 циклу хід C-Eb-E-G-F веде до F, а в такті 32
Входу — хроматичний підйом C-Db-D-Eb-E-F.

## 3. Три варіації одного мотиву

| Трек | Темп | Довжина | Лейтмотив |
|---|---|---|---|
| **Вхід** — «Головна тема» | 116 BPM (факт. 116,10) | 32 такти, 66,150 с | повний: спершу на духових (мелодія + терція вниз + секста вниз), далі на Rhodes октавою нижче, далі духові + Rhodes в октавах |
| **Завантаження** — «Петля завантаження» | 116 BPM (факт. 116,36) | 16 тактів, 33,000 с | уривки на Rhodes: перші половини тактів 1–4 теми, потім другі; так само для тактів 5–8; без духових |
| **Налаштування** — «Спокійна версія» | 84 BPM (факт. 83,92) | 16 тактів, 45,760 с | лише такти 1–4, **розтягнуті вдвічі** (аугментація на 8 тактів), повтор тихіше; гармонія теж розтягнута: акорд на 2 такти |

## 4. Бриф для зовнішнього композитора/генератора

Загальне: оригінальні мелодії й гармонія; **без цитат і парафраз існуючих творів, без імен
виконавців і назв треків, без сторонніх семплів із невільною ліцензією**; права — повна
передача/без атрибуції, можна продавати разом із грою. Завдання — замінити робочі
(синтезовані) версії живим або якіснішим звучанням, **зберігши тональність, темп,
структуру тактів, лейтмотив і точки петлі**, щоб кросфейди й синхронізація в грі працювали
без змін. Фінал: WAV 48 кГц 24 біт (стерео) + стеми, гучність **-16 LUFS інтегр., ≤ -1 dBTP**,
безшовна петля (хвости реверба й релізи перенесені через край). Номери тактів — 1-based.

### 4.1. Вхід — «Головна тема»

- **Жанр:** acid jazz / funk-rock; настрій: упевнений, «іду на арену», гострий, не агресивний.
- **Темп:** 116 BPM, 4/4, свінг шістнадцятих ≈ 9 %. **Тональність:** F мінор.
- **Інструменти:** слеп-бас (синкопи 16-х, октавні «попи», привидні ноти), Rhodes (комп і
  соло), секція духових (труби, тромбон, тенор-сакс; стаби й тема в терціях/секстах),
  wah-гітара (офбіт-чопи 16-ми), живі барабани (бочка, малий, привидні, закриті/відкриті
  хети, томи для філів, крештоп).
- **Структура (32 такти):**
  - A, 1–8: груув — барабани, слеп-бас, комп Rhodes; чопи гітари з такту 5; філ у такті 8.
  - B, 9–16: тема на духових (гармонізація; у такті 13 удари @2/@6); комп Rhodes; філ томів у такті 16.
  - C, 17–24: тема на Rhodes октавою нижче, гітара відповідає в паузах теми (кроки 7–8 тактів 17, 18, 19, 24);
    відкриті хети; «провал» у тактах 23–24 (барабани спрощені, бас довгими нотами); **філ барабанів у такті 24**.
  - D, 25–32: повний склад — тема на духових + Rhodes в октавах, бас зі «слепом» на першій долі, крештоп на
    початку; такт 32 — розворот (хроматичний хід баса, ударний філ), що безшовно веде в такт 1.
- **Петля:** весь кліп (такт 1 → такт 32 → такт 1), 3 175 200 семплів (66,150 с). Різке
  обрізання не допускається: хвости такту 32 мають звучати поверх такту 1.
- **Чого не робити:** не цитувати відомі рифи й теми; без вокалу; без довгих соло, що ламають
  петлю; не перестискати динаміку (піковий фактор лишити ≈ 14–17 дБ).

### 4.2. Завантаження — «Петля завантаження»

- **Жанр:** легкий груув на тому ж мотиві; настрій: бадьорий, ненав'язливий, «рух уперед».
- **Темп:** 116 BPM, F мінор, свінг ≈ 8 %. **Інструменти:** закриті хети + рим (cross-stick) +
  м'яка бочка, спрощений бас (корені й кілька попів), Rhodes (рідкісні уривки теми й м'який
  комп), легкий падь, дуже тихі чопи гітари. **Без духових, без крештопа, без різких піків.**
- **Структура (16 тактів):** 1–4 перші половини тактів 1–4 теми; 5–8 їхні другі половини;
  9–12 перші половини тактів 5–8; 13–16 їхні другі половини. Гармонія — той самий 4-тактовий цикл.
- **Петля:** весь кліп, 1 584 000 семплів (33,000 с); піковий фактор помірний (≈ 16 дБ).
- **Чого не робити:** великих кульмінацій; нічого, що заглушує сцену завантаження.

### 4.3. Налаштування — «Спокійна версія»

- **Жанр:** lo-fi / ambient; настрій: спокійний, теплий, не втомлює при тривалому перебуванні.
- **Темп:** 84 BPM, відчуття half-time, F мінор, свінг ≈ 14 %. **Інструменти:** Rhodes із
  тремоло, круглий бас (синус/трикутник), щітки й приглушені барабани на низькому рівні,
  теплий падь, дуже легкий тріск вінілу. Верх спектра м'який (зріз ≈ 6–7 кГц).
- **Структура (16 тактів):** лейтмотив — такти 1–4, розтягнуті вдвічі й зіграні двічі
  (такти 1–8 і 9–16, друге коло тихіше й рідше). Гармонія розтягнута вдвічі: Fm9 (1–2),
  Dbmaj9 (3–4), Bbm9 (5) + Eb13 (6), C7#9 (7–8), далі повтор.
- **Петля:** весь кліп, 2 196 480 семплів (45,760 с).
- **Чого не робити:** гострих ударних, яскравих духових, швидких мелодій.

### 4.4. SFX (за потреби замінити)

Один тембр: тон Rhodes + приглушений мідний «блип» + сухий дерев'яний клац. Довжини й ролі —
у таблиці розділу 1; тональність F мінор (помилка — навмисний дрібний секундовий
дисонанс). Пік ≤ -1 dBTP, без реверба або з дуже коротким.
