# «Ринг» — план кадрів приймання М1 (критерій 7 «Очима»), QA «Скилы», 08.11.2026

Мета: після Ф2 зняти все одним проходом, без сюрпризів. Для кожного пункту критерію 7: **чим знімати** (бот = `-ring-shots`,
демо = `-ring-demo`, меню = `-ring-menu-shots`, лукбук = `-ring-lookbook`, виходи = `-ring-entrances`) і **чого бракує**
(прапорець / кліп / екран — чия зона за `ZONES.md`). Стан коду — основна 7f19686 + те, що ПМ анонсував у Ф2.

черга Unity через ПМ. Огляд: аркуші ≤ 0,1 с на прийоми (демо `-ring-demo-every 0.1`), бот — кадр на такт (`beat_*`) +
`screens.txt`; поверх — фаз-тест `PlayedReport` (телепорти / канати / ковзання).

## 4. Чого бракує — зведено за зонами
- **Изучение (демо-ланцюг):** `-ring-demo-move <id>|all`, `-ring-demo-sex m|f`, `-ring-demo-pin 1|2|3`, крок больового
  (`-ring-demo-sub [rope]`), `-ring-demo-finisher <id>`, `-ring-demo-end countout|dco|dq`, матч «без DQ» з предметами,
  кроки «за ринг / повернути», обмін.
- **Кар'єра:** `-ring-shot-load`, `-ring-shot-ending` (задача 2), `-ring-shot-week all`, `-ring-shot-tier 1..4` або сейви
  рівнів, `-ring-shot-backstage all`, форсування подій, відмова від титульного шансу.
- **Бій:** таблиця фінішерів за `MoveKey`, `-ring-shot-repeat` (повтор прийому ботом).
- **Кліпи:** П3 п.1–п.6 (без них пункти бою — ❌ навіть з прапорцями).
- **Меню:** `-ring-lang en`, тур перемикачів «Гра».
- **Я (QA):** контакт-вочер (відстань кисть/тулуб до жертви на тактах Pin/Submission/Grapple, проникнення капсул) — зараз
  фаз-тест критерій 4 «взаємопроникнення < 3 см» не міряє; без нього лише очима. Потрібен дозвіл ПМ на файл у зоні
  **Изучение** (`RingStageWatch`) або окремий файл-вочер.

## 5. Порядок проходу приймання (≈ 9 запусків, ~3 год машинного часу)
1. Демо, кожен прийом × 2 статі, щільно 0,1 с (+ `-ring-demo-feet 1`) — 2 запуски.
2. Демо кінцівок і «за рингом»: pin 1/2/3, больові, фінішери, CountOut, DCO, DQ, без DQ з предметами — 1 запуск.
3. Бот 3 сезони, 1080 — фаз-тест сезону (критерій 4) + екрани кар'єри — 1 запуск (вже є база: pass3).
4. Бот із сейвів: 6 кінцівок, 4 рівні федерацій, тиждень «усі дії», закулісся — 1–2 запуски.
5. Меню + перемикачі на 1080 / 720 / 4:3 — 3 запуски (короткі); англійська — 1 запуск.
6. Виходи + лукбук — 1 запуск.
Звіт — у трьох розділах, на кожен пункт таблиць — ✅ / вада + кадр + зона.
