## 4. Мапа для GDD v7

Як читати: **пункт** — підпункт поправки (для поправок без підпунктів —
«абз.» і номер пункту в її списку «Що уточнюється»); **розділ GDD** — епік/US
і рядок `GDD.md` на HEAD `fbdfc0a`; **дія** — *замінити* (фрагмент GDD
зникає), *доповнити* (фрагмент лишається, додається текст), *новий розділ*,
*скасувати* (фрагмент GDD прибирається без заміни), *не в GDD* (процедура,
замір чи код — лишається в поправці або спеці); **статус** — затв. /
чернетка / пропозиція (пункт усередині затвердженої поправки, що рішенням
не є).

Чернеткові пункти вливаються з позначкою «ЧЕРНЕТКА — не затверджено» або
не вливаються до затвердження: видавати їх за затверджені не можна.
